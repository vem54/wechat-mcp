# Changelog

## 0.2.0 — public source preview

- Collect the MIT reader and GPL sender as separately licensed components.
- Add private local attachment export, paginated PDF text and bounded image previews.
- Support signal-aware archive watching independent of an AI client.
- Add native text submission with Mac-history integration and durable duplicate prevention.
- Observe late send results without resubmission; remove the former per-process send ceiling.
- Add deployment fingerprints, orderly native cleanup and synthetic lifecycle stress tests.
- Publish generic setup, privacy boundaries, provenance and a CI template without private runtime state.

The sender still requires manual exact-build validation; general onboarding and
cross-version compatibility are not claimed.
